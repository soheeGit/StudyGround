# Study Ground

한국공학대학교 캡스톤 과제입니다.

Study Ground는 온라인 스터디를 위한 플랫폼 입니다.

---

## 실행 방법

### npm run server

서버만 실행

### npm run client

클라이언트만 실행

### npm run dev

둘다 실행
